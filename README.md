# Student Grade Calculator

## Live Demo

[Open Student Grade Calculator](https://vasavithanuja.github.io/StudentGradeCalculator/)

A simple mobile-style Student Grade Calculator web application developed using HTML, CSS, and JavaScript.

## About the Project

Student Grade Calculator helps students calculate their academic performance easily.

Users can:
- Create an account
- Login to the application
- Enter student details
- Enter marks for 5 subjects
- Calculate total marks
- Calculate percentage
- Generate grade
- Check PASS/FAIL status
- View the latest result on the dashboard

## Features

- User Registration
- User Login
- Student Dashboard
- Grade Calculator
- Result Summary
- PASS/FAIL Calculation
- Local Storage Data Management
- Mobile-style User Interface
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Grade Calculation

| Percentage | Grade |
|---|---|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |
